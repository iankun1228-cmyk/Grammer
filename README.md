# 儿童汉语语法严肃游戏

一个面向儿童的汉语语法网页游戏，包含三个学习主题：词类知识（“的”的用法）、短语知识（动宾短语）和句子知识（被字句）。每个主题均有情境任务和分阶段练习。

## 运行

游戏由 HTML、CSS、JavaScript 和本地图片资源组成，无须安装依赖或构建。打开仓库根目录的 `index.html` 即可游玩。若浏览器限制本地文件访问，可在仓库目录启动静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000/`。

## 项目文件

- `index.html`：游戏入口
- `game.js`：关卡内容与交互逻辑
- `styles.css`：界面样式
- `assets/`：游戏所需的图片资源

建议使用桌面浏览器，或在横屏平板上体验。
